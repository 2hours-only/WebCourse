### 模块间数据流向

```javascript
用户操作 UI (点击按钮/座位)
    ↓
UI/Canvas 层监听 DOM 事件
    ↓
通过 EventBus.emit 发送事件 (如 'user:recommend', 'seat:clicked')
    ↓
MainController 监听 eventBus.on
    ↓
Main 调用业务逻辑层 (recommend.recommend)
    ↓
业务逻辑返回结果
    ↓
Main 调用 UI/Canvas 层更新 (uiPanel.setRecommendation, renderer.renderSeats)
    ↓
用户看到反馈
```
