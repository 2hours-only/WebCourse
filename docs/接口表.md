### 模块间数据

```javascript
// 0. 用户认证流程
用户输入账号密码
↓
UI 层监听登录按钮点击
↓
UI 层 emit('user:login', loginData)
↓
Main 层监听事件，调用 Storage.login()
↓
Storage 返回 User 对象
↓
Main 调用 User.isAdmin() 判断角色
↓
Main 调用 UIPanel.switchView('main') 或 UIPanel.switchView('admin')
↓
Main 初始化影院数据
// 1. 选票业务流程
用户操作 UI (点击按钮/座位)
↓
UI/Canvas 层监听 DOM 事件
↓
通过 EventBus.emit 发送事件
↓
MainController 监听 eventBus.on
↓
Main 调用业务逻辑层
↓
业务逻辑返回结果
↓
Main 调用 UI/Canvas 层更新
↓
用户看到反馈
// 2. 放映厅切换流程
用户在左侧面板选择小/中/大厅
↓
UI 层 emit('hall:switch', hallType)
↓
Main 层监听事件，读取对应 data/cinemaData.js 数据
↓
Main 调用 Cinema.reloadHallData(newRows, newCols, ..., curvature)
↓
Main 调用 CanvasRenderer.render() 重新绘制画面
// 3. 多选座位流程
用户按住 Ctrl 点击座位
↓
InteractionHandler 监听点击事件，检测 Ctrl 键
↓
emit('seat:clicked', { seat, isMultiSelect: true, isDragSelect: false })
↓
Main 监听事件，根据 isMultiSelect 决定是否追加选择
↓
Main 更新 selectedSeats 数组
↓
Main 调用 UIPanel.setSelectedSeats(seats, onRemove)
↓
Main 调用 CanvasRenderer.updateSeat(seat)
// 4. 观众评分流程
用户点击已选座位上的评分按钮
↓
UI 层 emit('seat:rating', { seatId, rating })
↓
Main 监听事件，调用 Storage.saveUserRating(seatId, rating)
↓
Main 更新该座位的综合评分
↓
Main 调用 CanvasRenderer.updateSeat(seat) 更新显示
// 5. 热度动态变化流程
用户在热度地图上选择日期
↓
UI 层 emit('heatmap:time-change', day)
↓
Main 监听事件，调用 HeatmapRenderer.setTimeDimension(day)
↓
HeatmapRenderer 根据 day 加载对应热度数据
↓
Main 调用 HeatmapRenderer.render() 重绘
// 6. 管理员后台与退票流程
管理员登录成功
↓
Main 监听 'user:login' 成功且 User.isAdmin() === true
↓
Main 调用 Storage.getAllOrders()
↓
Main 调用 UIPanel.renderAdminDashboard(orders, users)
↓
管理员点击退票
↓
UI emit('admin:refund-order', orderId)
↓
Main 监听事件，调用 Storage.refundOrder(orderId)
↓
Storage 返回退票后的 Order
↓
Main 获取该订单内的 Seat 列表，调用 seat.setStatus('available')
↓
Main 调用 CanvasRenderer.render() 更新座位状态
↓
Main 重新拉取订单并刷新后台视图
```
